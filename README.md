## PySocial — социальная сеть

Веб-приложение, разработанное на Python и Flask.

### Возможности
- Регистрация и авторизация
- Лента публикаций
- Лайки и комментарии
- Личные сообщения
- Список диалогов в стиле VK

### Технологии
- Python
- Flask
- SQLite
- HTML
- CSS
